1 Mit GitHub verbinden

Die Inhalte liegen im Repository klimaanpassung-oberland/massnahmendatenbank. Zum Veröffentlichen braucht die Seite einen persönlichen Zugangsschlüssel. Er bleibt in diesem Browser und geht nur an GitHub.

Nicht verbunden.

Wie bekomme ich einen Zugangsschlüssel?
  1. Bei GitHub anmelden und einen neuen „Fine-grained token“ anlegen.
  2. Resource owner: klimaanpassung-oberland. Repository access: „Only select repositories“ → massnahmendatenbank.
  3. Permissions → Repository permissions → Contents: „Read and write“. Sonst nichts.
  4. Expiration: so lang, wie die Organisation erlaubt (z. B. ein Jahr). Erzeugen, den Schlüssel kopieren und oben einfügen.

Mit „auf diesem Gerät merken“ verbindet sich die Seite danach bei jedem Öffnen von selbst, bis der Schlüssel abläuft. Das nur auf dem eigenen Rechner anhaken, nicht auf einem gemeinsam genutzten. Ohne den Haken gilt die Verbindung bis zum Schließen des Tabs.

Verlangt die Organisation eine Freigabe für solche Schlüssel, muss ein Organisations-Admin ihn einmal bestätigen.

2 Excel-Tabelle hochladen

Am einfachsten: den aktuellen Stand als Excel herunterladen, darin arbeiten und die Datei hier wieder hochladen.

Was in die Spalte „Steckbrief“ gehört
  • Ein Dateiname wie Gruendach.pdf — die Datei liegt dann im Repository im Ordner steckbriefe/ (in Schritt 3 hochladen). Groß- und Kleinschreibung zählt.
  • Oder ein vollständiger Link wie https://www.energiewende-oberland.de/…/Gruendach.pdf, wenn die Datei woanders liegt.
  • Ein in Excel eingefügter Hyperlink geht auch: Dann zählt der Link, nicht der angezeigte Text.

4 Prüfen und veröffentlichen

Noch keine Tabelle hochgeladen.

Ohne Zugangsschlüssel veröffentlichen
  1. Oben „Nur CSV herunterladen“ und die Datei in massnahmen.csv umbenennen.
  2. Bei GitHub im Ordner daten/ → „Upload files“ hochladen; die alte Datei wird ersetzt.
  3. PDFs genauso im Ordner steckbriefe/ hochladen.

↺ Frühere Stände

Jede Veröffentlichung bleibt dauerhaft erhalten, auch wenn danach versehentlich eine leere oder falsche Tabelle hochgeladen wurde. Ein früherer Stand lässt sich als Excel herunterladen oder wiederherstellen. Beim Wiederherstellen wird er in Schritt 4 geprüft und verglichen und erst dann als neuer Stand veröffentlicht.

Sichtbar nach dem Verbinden in Schritt 1.
